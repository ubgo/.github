# ubgo/.github

This is the `.github` repository of the [ubgo](https://github.com/ubgo) organization. GitHub shows [`profile/README.md`](profile/README.md) on the organization page.

`profile/README.md` is generated. Do not edit it here. The library list lives in `data/libraries.yaml` in the [ubgo.github.io](https://github.com/ubgo/ubgo.github.io) repo; edit it there and run `task profile`, which rewrites `profile/README.md` and copies the logo next to it.
